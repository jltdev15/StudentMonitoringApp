# Animated Teacher GIFs

Generated animated GIF versions of the teacher sprites.

Folders:
- `512/` - full-size GIFs, 512x512 px
- `256/` - mobile-optimized GIFs, 256x256 px
- `preview.html` - quick local preview

Included animations:
- teacher_idle_breathing.gif
- teacher_wave.gif
- teacher_talking.gif
- teacher_thinking.gif
- teacher_success.gif
- teacher_presenting.gif
- teacher_sad.gif

Note:
GIF supports only 1-bit transparency, so edges may look slightly less smooth than PNG frames.
For best quality in React Native, PNG frame-by-frame is still cleaner.
For easier app integration, the 256px GIFs are recommended.
